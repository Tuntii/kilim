# kilim Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** iyi için SDL3 üzerinde sıfırdan yazılmış, V `ui` tarzı retained-mode bir GUI kütüphanesi (`kilim`) ve onu kanıtlayan, Windows/Linux/macOS'ta çalışan bir todo örneği.

**Architecture:** Çekirdek (geometri, olaylar, widget ağacı, layout, odak, dağıtım) SDL'den bağımsızdır ve soyut bir `Canvas` ile `Clipboard` üzerinden çizer/ölçer. Bu yüzden testler SDL olmadan çalışır. Tek backend modülü (`kilim/sdl*.iyi`, `kilim/window.iyi`) SDL3 olaylarını kilim olaylarına çevirir, `SdlCanvas` ile çizer ve döngüyü yönetir. Kullanıcı API'si `kilim.iyi` içindeki builder fonksiyonlarıdır.

**Tech Stack:** iyi 0.20.0 (düz `.iyi`, `--crystal` yok), SDL3 + SDL3_ttf (FFI: `@[Link] lib ... fun`), gömülü Noto Sans (OFL), GitHub Actions (windows-latest, ubuntu-24.04, macos-14 arm64).

**Spec:** `docs/superpowers/specs/2026-11-03-kilim-design.md`

## Global Constraints

- iyi sürümü **0.20.0**'a sabit. CI ve README bu sürümü kurar.
- `--crystal` yok. Crystal stdlib ya da shard kullanılmaz.
- Sadece SDL3 ve SDL3_ttf bağlanır. raygui, microui, imgui, libui, GTK yok.
- Hedefler: Windows x86-64 (MSVC), Linux x86-64 glibc, macOS arm64 14.4+.
- Çekirdek modüller (`geom`, `event`, `canvas`, `theme`, `widget`, `box`, `label`, `button`, `checkbox`, `text_edit`, `textbox`, `scroll`, `ui`, `testing`) `kilim/sdl*` ya da `kilim/window` import etmez. Testler SDL linklemeden derlenir.
- C→iyi callback'i yalnızca bir tane: `SDL_AddEventWatch` (canlı resize). `SDL_AddTimer` vb. eklenmez. İmleç yanıp sönmesi `SDL_WaitEventTimeout` ile yapılır.
- Koordinatlar mantıksal birimdedir (`Float32`). Piksel yoğunluğu yalnızca `SdlCanvas` içinde uygulanır.
- Boştayken yeniden çizim yapılmaz: yalnızca bir olay ya da `invalidate` olunca çizilir.
- Kopyala: seçim yok, Ctrl/Cmd+C textbox'ın tüm metnini kopyalar. Ctrl/Cmd+V imlece yapıştırır. "Primary" değiştirici macOS'ta Cmd, diğerlerinde Ctrl'dir.
- Tek açık tema, sabitler `kilim/theme.iyi`'de. Tema API'si yok.
- iyilang/iyi'ye issue/PR açmadan önce kullanıcıya sorulur. Bir iyi hatasının etrafından dolaşılırsa koda `shortcut:` yorumu yazılır.
- Font: `assets/fonts/NotoSans-Regular.ttf` + `assets/fonts/OFL.txt`, `read_file` makrosuyla gömülür.

## Review Focus

1. **Bir widget kendi event handler'ı içinde ağaçtan silinirse** ("Sil" butonu kendi satırını siler), odak, hover ve capture temizlenir ve çökme olmaz. Test: Task 5 `test/removal_test.iyi`.
2. **Ağaç dispatch sırasında değişirse** (Enter → `list.add`), iterasyon çökmez ve yeni çocuk bir sonraki frame'de layout'a girer. Test: Task 4 `test_add_during_click`.
3. **Textbox'tan geniş metin yazılırsa** imleç her zaman görünür kalır (`scroll_x`). Test: Task 6 `test_caret_stays_visible`.
4. **Pencere 0×0'a ya da içerikten küçüğe indirilirse** negatif boyut oluşmaz ve çökme olmaz. Test: Task 3 `test_zero_rect`.
5. **İçerik küçülünce** (öğe silindi) scroll offset'i yeniden sınırlanır ve altta boşluk kalmaz. Test: Task 7 `test_offset_clamped_after_shrink`.

### Task 3: Box layout (row/column)

**Files:**
- Create: `kilim/box.iyi`, `test/layout_test.iyi`

**Interfaces:**
- Consumes: `Widget`, `Sizing`, `Rect`, `Size`, `Canvas`.
- Produces: `pub enum Axis { Row, Column }`. `pub class Box < Widget`:
  - `initialize(axis : Axis, children = [] of Widget, padding : Float32 = 0, spacing : Float32 = 0, sizing = Sizing.fit)`
  - `add(w : Widget)`, `insert(i : Int32, w : Widget)`, `remove(w : Widget)`, `clear`. Hepsi `parent`'ı ayarlar ya da temizler ve `invalidate` çağırır.

**Layout algoritması** (ana eksen = axis; çapraz eksen her zaman stretch):
1. `inner = bounds.inset(padding)`.
2. Fit çocuklar `preferred`, Fixed çocuklar `value` boyutu alır.
3. Kalan alan şöyle hesaplanır: `max(0, inner_main - fit/fixed toplamı - spacing * (n - 1))`. Bu alan Fill çocuklara `weight` oranında dağıtılır.
4. Çocuklar sırayla yerleştirilir. Çapraz boyut `inner_cross`'tur. Hiçbir boyut negatif olmaz.

`preferred` şöyle hesaplanır: ana eksende Fit/Fixed boyutları, Fill'lerin `preferred` boyutları, aralıklar ve `2 * padding` toplanır. Çapraz eksende çocukların en büyüğü alınır ve `2 * padding` eklenir.

- [ ] **Step 1: Testleri yaz.**

```crystal
# column(padding 10, spacing 5): Fixed(20) + Fill(1) + Fill(1); layout Rect(0,0,200,200)
expect_eq a.bounds, Rect.new(10, 10, 180, 20), "fixed"
expect_eq b.bounds.h, 77.5_f32, "fill payı: (180-20-10)/2"
expect_eq c.bounds.y, 10 + 20 + 5 + 77.5 + 5, "sıra + spacing"
# test_row_fit: row içinde Fit(40x20) dummy'ler -> preferred == Size(40*n + spacing*(n-1), 20)
# test_zero_rect (Review Focus 4)
box.layout(Rect.new(0, 0, 0, 0), canvas)
box.children.each { |w| expect w.bounds.w >= 0 && w.bounds.h >= 0, "negatif boyut yok" }
```

- [ ] **Step 2:** `iyi run test/layout_test.iyi`. Beklenen: FAIL.
- [ ] **Step 3:** `Box`'ı uygula.
- [ ] **Step 4:** PASS.

**Files:**
- Create: `kilim/label.iyi`, `kilim/button.iyi`, `test/button_test.iyi`

### Task 7: Scroll

**Files:**
- Create: `kilim/scroll.iyi`, `test/scroll_test.iyi`

**Interfaces:**
- Produces: `pub class Scroll < Widget`:
  - `initialize(child : Widget)`, `offset : Float32`, varsayılan `sizing = Sizing.fill`.
  - `preferred` = çocuğun genişliği + `SCROLLBAR_W`, yükseklik `CONTROL_H` (gerisini Fill sağlar).
  - `layout`:
    - `content_h = child.preferred.h`
    - `offset = clamp(offset, 0, max(0, content_h - bounds.h))`
    - Çocuk `Rect(x, y - offset, w - SCROLLBAR_W, content_h)` ile yerleştirilir.
  - `handle(Wheel)` → `offset -= dy * WHEEL_STEP`, ardından clamp ve invalidate. Olay bubbling ile Scroll'a ulaşır, yani üstündeki bir buton da tekerleği iletir.
  - `draw` çocuğu `push_clip(bounds)` ile çizer ve `pop_clip` yapar. İçerik taşıyorsa sağda `SCROLLBAR` rengiyle orantılı bir başparmak (thumb) çizer.
  - `hit` önce `bounds`'u kontrol eder; bu yüzden görünür alanın dışındaki çocuklar tıklanamaz.

### Task 8: SDL backend — SdlCanvas, Window, döngü

**Files:**
- Create: `kilim/sdl_canvas.iyi`, `kilim/window.iyi`, `assets/fonts/NotoSans-Regular.ttf`, `assets/fonts/OFL.txt`
- Modify: `kilim/sdl.iyi` (gereken fun'lar), `examples/smoke.iyi` (bir Label ve Button'lı Window ile yeniden yazılır)

**Interfaces:**
- Consumes: `Canvas`, `Clipboard`, `Ui`, `Event` alt sınıfları, `Widget`.
- Produces:
  - `pub class SdlCanvas < Canvas`:
    - `initialize(renderer, density : Float32)`. Tüm koordinatlar `density` ile çarpılır.
    - Font gömülü bayttan açılır: `read_file` → `SDL_IOFromConstMem` → `TTF_OpenFontIO`, boyut `FONT_SIZE * density`.
    - `text` her çağrıda yüzey ve doku oluşturup çizer ve yok eder. Kodda `shortcut: her frame metin dokusu yeniden üretilir, büyük listelerde yavaşlarsa (metin, renk) önbelleğine geçilir` yorumu bulunur.
    - `measure` için `TTF_GetStringSize` kullanılır ve sonuç `/ density` olur.
    - `push_clip`/`pop_clip` bir yığın tutar, kesişim alır ve `SDL_SetRenderClipRect` çağırır.
    - `set_density(d)` pencere ekranlar arasında taşınınca fontu yeniden boyutlandırır.
  - `pub class SdlClipboard < Clipboard`: `SDL_SetClipboardText` / `SDL_GetClipboardText` (+ `SDL_free`).
  - `pub class Window`:
    - `initialize(title : String, width : Int32, height : Int32, root : Widget)`. `SDL_WINDOW_RESIZABLE | SDL_WINDOW_HIGH_PIXEL_DENSITY` ile açılır.
    - `run` döngüsü:
      - Bloklayıcı bekleme yapar. `ui.wants_text_input?` ise `SDL_WaitEventTimeout(BLINK_MS)` kullanılır, zaman aşımında `ui.blink` çağrılır. Değilse `SDL_WaitEvent` kullanılır.
      - Ardından `SDL_PollEvent` ile kuyruk boşaltılır, olaylar çevrilip `ui.dispatch` edilir. `ui.frame` true dönerse `SDL_RenderPresent` çağrılır.
      - `SDL_EVENT_QUIT` ve `WINDOW_CLOSE_REQUESTED` döngüyü bitirir.
    - `wants_text_input?` değişince `SDL_StartTextInput` / `SDL_StopTextInput` çağrılır.
    - Olay çevirisi:
      - mouse motion/button/wheel → `MouseMove`/`MouseDown`/`MouseUp`/`Wheel` (wheel y float, `SDL_MOUSEWHEEL_FLIPPED` dikkate alınır)
      - key down → `KeyDown` (keycode → `Key`; `primary` = darwin'de `SDL_KMOD_GUI`, diğerlerinde `SDL_KMOD_CTRL`; bu ayrım `{% if flag?(:darwin) %}` ile yapılır)
      - text input → `TextInput`
      - pixel size changed / display scale changed → `Resize` + `set_density`
    - Canlı resize: `SDL_AddEventWatch` ile kaydedilen, closure olmayan bir proc `WINDOW_RESIZED`/`WINDOW_EXPOSED` olaylarında `ui.resize` + `ui.frame` + `present` yapar. Userdata `Box.box(self)` olur ve kutu `@watch_box` ivar'ında tutulur. `close` içinde `SDL_RemoveEventWatch` çağrılır.
    - `inject(e : Event)` (`ui.dispatch`), `step` (bekleme yapmadan kuyruğu boşaltıp bir frame çizer), `screenshot(path : String)` (`SDL_RenderReadPixels` + `SDL_SaveBMP`), `ui : Ui`, `close`.
